# tickets

Unified issue tracking across GitHub, GitLab, and Jira from one CLI/daemon
and one Pi extension — query and mutate issues the same way from either.

Bun workspace with two published packages:

- [`packages/tickets`](packages/tickets/README.md) — `@danypops/tickets`, the CLI/daemon/library.
- [`packages/pi-tickets`](packages/pi-tickets) — `@danypops/pi-tickets`, the Pi extension.

See each package's own README for usage.
